# 一步 · 网页客户端

运行 `node api-server.cjs`，打开 http://127.0.0.1:4174/ 。服务端读取环境变量 `DEEPSEEK_API_KEY`。不要直接从文件系统打开网页。

当前 UI 根据实际向 Opus 5.5 咨询得到的“作业本”方案重写。旧视觉与动效文件不再加载，恢复备份位于 `legacy-ui/`。原有 `yibu-prototype-v1` 本地数据继续使用。

已实现：课程与普通聊天、连续对话、草稿恢复、真实 DeepSeek 教学、会话删除确认、公式卡片与 LaTeX 排版、题24演示记录、实际追问原话、折叠答案和完整聊天、搜索、复习自评、文件名保存、记录导出/导入。

“下一题”只对已经提供的多题作业出现。目前可以识别带题号、按行分隔的多题文本，例如：

```text
24. 设 P(A|B)+P(非A|非B)=1，证明 A 与 B 独立。
25. 若 A、B 独立且概率均为正，证明 A 与 B 相容。
```

只有一道题，或没有可靠的题目列表时，不显示“下一题”。“下一题”的题目列表目前来自带题号的多题文本，不自动根据图片生成。

聊天支持粘贴、选择和拖入图片。先显示可移除的缩略图，点击发送后显示真实图片，可点击放大；支持单独发图。资料页导入的图片也会保留原图，可预览或点击聊天图标带入当前课程的对话。图片存入 IndexedDB，刷新或换会话仍保留，导出/导入记录包含图片。每次最多添加4张，单图超过2MiB时压缩；教学请求携带最近8张图片，按 DeepSeek 官方图片内容块格式发送。早期只保存文件名的附件无法恢复图片内容，需要重新添加。

公式使用本地 KaTeX 0.18.9（MIT）排版，无须连接第三方 CDN。数学公式、普通文字与用户消息区分显示；旧消息中的裸概率公式也会处理。渲染不会修改数学结论。完整消息保存在本地；每次教学请求发送最近80条相关消息，并补充最近题干。

当前没有账号/云同步、通用自动题目总结或独立 OCR 引擎；图片由 DeepSeek 原生视觉直接读取。“试试第24题”及默认测试聊天已移除，已有历史聊天不受影响。旧的题24记录模板暂保留给现有记录，其他题目尚无自动总结。PDF、Word等课程资料仍只保存名称，内容尚未接入。桌面网页和 iPhone 各自保存本地数据；本次图片输入修复在网页端，iOS 0.3.1新增的是直接配置模型并移除示例入口。

检查：`node verify-ui.cjs`、`node verify-math.cjs`。使用 Playwright 与 Edge，在1440×900及402×874验证课程导航、切换会话中的请求归属、草稿、失败重试、记录搜索、折叠、附件文件名、删除、导出、单题/多题下一题规则、数学上划线和 reduced motion。真实 DeepSeek 请求已返回成功。手机软键盘和实际 iPhone 的触摸体验仍需真机验收。
