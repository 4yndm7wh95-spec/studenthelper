# 一步 · 全新 UI / UX / 动效规格 v2

本规格替换全部旧前端视觉与动效，不继承任何旧样式、旧类名或旧动画。以下内容保持不变：`app.js` 的数据结构、教学演示数据、`POST /api/chat` 调用链路，以及 localStorage 键 `yibu-prototype-v1`。

---

## 0. 设计方向

**方向名：作业本。**

整体像一本摊开的作业本：
- 左侧是按课程分好的本子。
- 右侧是一页一页往下写的对话。
- 做完的题会被收进“记录”这一格。

视觉规则：
- 暖白纸面，深墨文字。
- 只用一种强调色“墨蓝”。
- “没懂的地方”一律用琥珀色。
- 界面层级只有三层：纸面、卡片、浮层。
- 不用毛玻璃、渐变或大阴影。

动效规则：
- 动效像“翻页、落笔、展开”：有方向，略带回弹，偏慢收尾。
- 只在位置或层级改变时才动。
- 阅读区的文字永远不做逐字动画。

## 1. 信息架构与组件

### 1.1 IA 决策

```
一步
├─ 左栏（本子）
│  ├─ 新对话按钮
│  ├─ 普通对话（单行入口，点开后在左栏下方列出普通会话）
│  ├─ 课程（分组标题 + [+]）
│  │   └─ 课程行（手风琴，同时只展开当前课程）
│  │       └─ 该课程的会话列表（最近 8 条 + “全部 n 条”）
│  └─ 底部：账号状态胶囊（本机保存）
└─ 右侧主区（当前课程）
   ├─ 顶栏：标题 + 题目跳转 + 三个标签 [对话][记录][资料]
   ├─ 对话：连续多题
   ├─ 记录：列表 → 题目详情；列表顶部有“复习”入口
   └─ 资料：本课程文件名
```

各页面的位置：
- **普通对话**：只有“对话”，不显示“记录”和“资料”标签，也不显示附件按钮。这样可以减少选项。
- **复习**：不单独占导航。从“记录”页右上角的 `复习` 按钮进入，是记录的子视图。
- **账号**：底部胶囊点开的浮层，不做成页面。
- **新建课程**：桌面端用小对话框，手机端用底部抽屉。

### 1.2 路由（hash，用于支持浏览器返回）

| 路由 | 视图 |
|---|---|
| `#/chat/:sessionId` | 对话。课程由 `session.course` 决定 |
| `#/c/:course/records` | 记录列表。可带 query：`?q=&f=asked` |
| `#/c/:course/records/:recordId` | 题目详情 |
| `#/c/:course/review` | 复习 |
| `#/c/:course/files` | 资料 |

路由规则：
- 课程名要用 `encodeURIComponent` 编码。
- 普通对话沿用 `app.js` 现有的 course 标识值，不新造字段。
- 浮层（抽屉、对话框、浮层菜单）通过 `history.pushState({layer:'drawer'})` 入栈。在手机上按系统返回键，会先关闭浮层，而不是离开页面。

### 2.1 字体与字重（照顾中国 Windows）

**字重**
- Windows 的微软雅黑实际只有 400 和 700 两档。写 500 会渲染成 400，写 600 会渲染成 700。
- 因此层级差异主要靠**字号 + 颜色**，不能依赖字重：
  - 主文字用 `--ink`，次文字用 `--ink-2`。
  - 相邻两级的字号至少相差 2px。
- 需要强调时只用 600，并且同一视图最多 3 处加粗。

**数学字体**
- 数学内容用 `<span class="math">` 包裹，字体为 `--font-math`。
- Windows 自带 Cambria Math，可以正确显示 `Ā`、`B̄`、`∣`、`≤`。
- 字号统一放大到 `1.06em`。

**整体排版**
- 全局设置 `-webkit-font-smoothing:antialiased; text-rendering:optimizeLegibility;`。
- 中文正文不要设置 `letter-spacing`。

### 2.2 断点

| 名称 | 宽度 | 布局 |
|---|---|---|
| `m` | ≤ 767 | 左栏变为抽屉，宽 `min(86vw, 320px)`；顶栏 52px + 标签行 40px；触控区 44px |
| `md` | 768–1199 | 左栏常驻 248px；对话列最大宽 `min(720px, 100% - 48px)` |
| `lg` | 1200–1599 | 左栏 280px；对话列 720px 居中 |
| `xl` | ≥ 1600 | 左栏 280px；对话列 760px；题目详情右侧出现 200px 的分节目录（sticky） |

所有 hover 效果都包在 `@media (hover:hover)` 里，避免手机上出现粘住的 hover 状态。

### 2.3 图标

- 使用 Lucide 风格的内联 SVG，`viewBox 0 0 24 24`。
- 描边 `1.75`，`stroke-linecap:round`，颜色继承 `currentColor`。
- 标准尺寸 20px，副行内使用 16px。

| 用途 | 图标 | 是否带文字 |
|---|---|---|
| 新对话 | `square-pen` | 桌面带文字“新对话” |
| 普通对话 | `message-circle` | 带 |
| 添加课程 | `plus` | 仅图标，有 tooltip |
| 展开 | `chevron-right`（旋转 90°） | 否 |
| 标签：对话 / 记录 / 资料 | `message-square` / `notebook-text` / `paperclip` | **必须带文字** |
| 发送 | `arrow-up` | 否 |
| 附件 | `paperclip` | 否 |
| 重试 | `rotate-ccw` | 带“重试” |
| 搜索 | `search` | 否 |
| 复习 | `repeat-2` | 带“复习” |
| 看答案 | `eye` | 带“看答案” |
| 回到聊天 | `corner-up-left` | 带“回到聊天” |
| 没懂的地方 | `circle-help`（琥珀色） | 带 |
| 本机保存 | `hard-drive` | 带 |
| 同步未接入 | `cloud-off` | 带 |
| 菜单 | `menu` | 否 |
| 关闭 | `x` | 否 |

### 2.4 插画

只用于 3 个空状态，每幅 120×96 的内联 SVG：
- 线条为 `--ink-3`，描边 1.5；只有一处点缀用 `--accent`。
- 不铺底色，不做动画。

三幅内容：
1. **对话空**：一张横线纸，上面有一支斜放的铅笔，笔尖是一个蓝点。
2. **记录空**：一本合上的本子，书签是蓝色。
3. **资料空**：一个回形针别着一张空纸片。

## 3. 页面线框与规格

### 3.1 桌面 · 对话（有消息）1280×800

```
┌────────────────────────┬───────────────────────────────────────────────────────┐
│ 一步          [✎ 新对话] │ 第24题作业  ·  [第24题 ▾]        [对话|记录|资料]      │56
│                        ├───────────────────────────────────────────────────────┤
│ 💬 普通对话             │                                                       │
│                        │        ┌ 题目 ──────────────────────────────┐         │
│ 课程              [+]  │        │ 设 0<P(A)<1，0<P(B)<1，             │         │
│ ▾ ● 概率论          3   │        │ P(A|B)+P(Ā|B̄)=1，证明 A 与 B 独立。  │         │
│   ▌第24题作业      📓   │        └────────────────────────────────────┘         │
│    第3章作业           │   先看第二项 P(Ā|B̄)。它和哪个条件概率加起来是 1？      │
│    第2章作业           │                                     ┌──────────┐      │
│ › ● 线性代数        1   │                                     │  不知道   │      │
│                        │                                     └──────────┘      │
│                        │   是 P(B̄ 条件下的 A)。所以 P(Ā|B̄)=1−P(A|B̄)。          │
│                        │   代进原式，你会得到什么？                             │
│                        │        ─────────── 第25题 ───────────                 │
│                        │                                                       │
│                        │           [不会这步]  [看完整答案]                     │
│                        │    ┌────────────────────────────────────────────┐     │
│ ⛁ 本机保存 ·           │    │ 📎 │ 说说你的想法…                     │ (↑) │     │
└────────────────────────┴────┴────────────────────────────────────────────┴─────┘
```

**左栏**（`--paper-side`，右边 1px `--line`，内边距 12px）

- **品牌行**（高 48）：
  - 左侧是“一步”，字体 `--t-title`。
  - 右侧是 `yb-btn secondary` “新对话”，高 32。
- **普通对话行**：
  - 高 36，圆角 `--r-sm`，图标后接文字。
  - 选中后，行下方缩进展开普通会话列表，规则与课程下的会话一致。
- **分组标题“课程”**：
  - 字体 `--t-cap`，颜色 `--ink-3`，上边距 20。
  - 右侧有 `+` 图标按钮，尺寸 28×28。
- **课程行**：
  - 高 36；依次为 chevron 16、课程色点 8、课程名（`--t-label`，超长省略）、会话数（`--t-cap`，`--ink-3`）。
  - 当前课程：背景透明，文字 `--ink` 并加 600。
- **会话行**：
  - 高 34，左侧缩进 28，字体 `--t-body` 缩到 14px。
  - 当前会话：背景 `--accent-soft`，文字 `--accent`，左侧有 3px 的内侧色条（`::before`，圆角 full）。
  - 行尾 `📓`（`notebook-text` 16px，`--ink-3`）只在该会话含 `record:true` 的消息时出现，tooltip 为“有整理好的记录”。
  - 有草稿时，标题前加“草稿·”，字体 `--t-cap`，颜色 `--amber`。
- **底部胶囊**（sticky bottom）：
  - 高 36，内容为 `hard-drive` 图标 + “本机保存” + 右侧 6px 圆点 `--ok`。

**顶栏**（高 56，底边 1px `--line`，背景 `--paper`）

- 左侧会话标题，字体 `--t-title`。双击或点击都不能改名，因为没有这个功能。
- 标题右侧是 `yb-jump`：
  - 这是一个 ghost 按钮，文字为当前视口所在题号，例如“第24题 ▾”。
  - 当会话里有 ≥2 个 `paper` 或 `divider` 消息时才显示。
- 最右侧是 `yb-tabs`（见 3.9）。

**对话列**（最大宽 720，居中；上下内边距 24 / 160，给输入区留空间）

- **老师消息**：
  - 无气泡，字体 `--t-read`，颜色 `--ink`。
  - 段落间距 8，消息之间间距 20。
  - 左侧没有头像，也不写名称。
- **学生消息**：
  - 右对齐，最大宽 80%。
  - 背景 `--accent-soft`，文字 `--ink`，圆角 `14 14 4 14`，内边距 `10 14`，字体 `--t-read`。
- **题目卡 `paper`**：
  - 背景 `--surface-sunk`，1px `--line`，圆角 `--r-lg`，内边距 `16 20`。
  - 左上角小标签“题目”，字体 `--t-cap`，颜色 `--ink-3`。
  - 正文 `--t-read`，公式使用 `.math`。
- **分题线 `divider`**：
  - 两侧 1px `--line`，中间文字（例如“第25题”）字体 `--t-cap`，颜色 `--ink-3`。
  - 上下间距各 32。
- **已整理卡 `record:true`**：
  - 高 52，背景 `--surface`，1px `--line`，圆角 `--r-lg`。
  - 内容为 `notebook-text`（颜色 `--ok`）+ “第24题已收进记录” + 右侧 ghost 按钮“查看 ›”。
  - 这张卡不打断对话，下一条消息照常接在后面。
- **失败行 `yb-fail`**：
