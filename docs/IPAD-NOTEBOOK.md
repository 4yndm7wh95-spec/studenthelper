# 一步 0.5 · iPad 笔记本

这一轮参考本项目聊天「开发AI笔记本」中的手写需求，把原有教题应用扩展成可以日常使用的 iPad 笔记本。界面直接复用现有暖纸色、陶土色强调和文字层级。原有教题、记录、文件与复习仍然可用。

## 使用

iPad 启动后默认进入笔记本书架。新建一本笔记，选封面和纸张后直接进入书写页面。

- Apple Pencil 书写；默认手指不落墨。笔记本选项中可以开启手指书写。
- 双指移动和缩放纸张。钢笔、荧光笔、整笔擦除、局部擦除和套索使用 PencilKit。
- 颜色和粗细可调整，自选颜色保存在最近使用列表。
- 图片可从照片或文件插入。插入后进入套索模式，用手指移动图片、拖右下角调整大小或删除。用 Pencil 套索移动原生笔迹。
- 页面条和底部翻页按钮可切页；纸张可选空白、横线、方格和点阵。长按缩略图可重命名、排序和删除。
- 笔迹在每次落笔结束后保存，页面、对象修改自动保存。失败时保留未保存的笔迹并提供重试。退出到后台也会尝试保存。
- 撤销和重做覆盖手写、图片和页面操作；操作历史保留在本次运行中，不跨重启。

## 笔记助手

题目图片默认等比放在页面上方，占用不超过纸高35%，下方留给手写推导。点击星光图标进入助手：提问默认发送整页图片、识别文字与页面结构，让模型同时看到题目和解题过程。框选时另外附上局部放大图。图片按钮可以关闭；关闭后仅传文字与结构。这需要支持图片的模型，默认 DeepSeek Flash 支持视觉输入。

助手复用现有模型地址、模型名和 Keychain 密钥。当前仅直接连接模型模式可用，原有教学后端尚无笔记工具接口。可以在助手里打开模型设置。

当前页读取工具：`list_pages`、`read_page`、`read_region`、`search_notes`。用户要求查看其他本时，助手可通过 MCP 的 `list_notebooks`、`list_notebook_pages`、`read_notebook_page`、`search_notebook` 读取目标内容。搜索使用本机 OCR 加关键词，分批读取；结果会给出覆盖范围。这不是完整的语义索引，不能保证查到所有手写公式。

助手优先检查第一处实质错误，解释原因并给出该行正确写法；看不清的笔迹需要询问，不猜。AI 可以直接画圈、下划线、添加纠正、翻页、缩放或整理；原始解法默认保留。也可以先提出修改建议，用户点击“应用修改”后整批保存。所有笔记操作可撤销，回复期间页面变化会阻止应用过期建议。

AI 操作期间以缓入缓出边光、光点和一句短状态显示进度，触控和键盘暂时锁定。助手面板会收起，让纸张可见；停止按钮始终可用。停止后恢复操作，已保存的修改仍可撤销。动画支持系统的减少动态效果。

App 内助手通过 MCP JSON-RPC 的本进程传输调用与外部相同的工具。设置→AI 连接→允许连接可启动局域网 Streamable HTTP `/mcp` 服务，复制配置给同网络的 MCP 客户端。每次开启会生成新的 Bearer 连接凭据；外部客户端需要传 Authorization、Accept 和 MCP-Protocol-Version。服务支持 initialize、tools/list、tools/call、ping、取消通知；GET/SSE 未提供（返回405），使用JSON响应。退到后台自动停止服务。外部操作期间按停止会同时关闭连接许可，须重新开启并复制配置。

统一工具包含读取软件状态、笔记本/页面/原生笔迹、关键词检索与应用操作。动作涵盖笔记本/页面/图片/注释管理、原生绘制/移动/擦除、滚动缩放、画笔、导航，以及原有课程、教题、资料与复习的公开功能。相册、文件选择器与系统权限弹窗仍由用户处理；API Key 不暴露给工具。外部连接仅适用于可信局域网、前台运行，不提供公网云中继。

## 保存结构

`Application Support/notebooks/library.json` 是带版本号的原子索引；原生 `PKDrawing` 存在 `drawings/*.pkdraw`，带 SHA-256 完整性校验，图片存在 `images/*.png`。纸张与对象坐标独立保存，导出给 AI 的截图不会代替原始笔迹。

所有对象坐标使用未缩放的纸张坐标。一次修改先写不可变附件，再原子替换索引。保存失败保留旧索引。附件清理保留所有撤销/重做状态引用；遇到损坏索引，默认保护原文件，显式备份之后才能新建库。

聊天继续使用原有 `learning-state.json` 和 `image-assets`，无需迁移旧聊天数据。当前没有账号、CloudKit 或跨设备同步。

## 验证与构建

`ios/project.yml` 配置 iPadOS 17+、仅 iPad 安装包和 iPad 四方向旋转，支持窗口变窄时重新布局。版本为0.5.0（10）。本轮暂不开发 iPhone 版。

云端流程先编译模拟器，在 iPad 上执行文档保存、模型请求、图片持久化等单元测试及笔记本界面测试、截图，最后编译物理设备和打包未签名 iPad IPA。签名安装需要原有侧载流程。

本地语法检查只检查 Swift 语法与资源，不能代替 Xcode 编译。Pencil 的压感、延迟、防误触、原生套索和双指操作最终仍需 iPad 真机验收。不会把模拟器上的手指绘制宣称为已达到 Goodnotes 手感。

技术依据：[Apple PencilKit](https://developer.apple.com/documentation/pencilkit/pkcanvasview)、[原生笔迹保存与渲染](https://developer.apple.com/documentation/pencilkit/pkdrawing-swift.struct)、[Vision 文字识别](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)、[DeepSeek 工具调用](https://api-docs.deepseek.com/guides/tool_calls/)。
